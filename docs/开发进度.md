## 版本升级与 Isar → Drift 迁移（2026-08-20）

用户决策：放弃 Isar，迁移 Drift(SQLite)，避免长期版本升级冲突；Flutter 升至 3.41.0（不锁死）。

| 项 | 说明 |
| :-- | :-- |
| Flutter/Dart | 3.32.0 → **3.41.0 / Dart 3.11**（.fvmrc 同步）；meta 1.17.0、material_color_utilities 0.13.0 随 SDK 升级 |
| 数据库 | Isar 4.0-dev → **Drift 2.30 + drift_flutter + sqlite3_flutter_libs**；7 张表（Diaries/Categories/Fonts/Blocks/AppMetadata/CrmEntityCaches/SyncRecords） |
| 工具链 | build_runner 2.14.0（build 4 / analyzer 8）、drift_dev 2.30、json_serializable 6.14.1、flutter_gen 5.15.0 |
| 代码生成 | 移除 freezed（6 个模型转普通 json_serializable 类）；Drift @DataClassName 避免与业务模型重名 |
| IsarUtil | 保留全部公开接口，内部切换 Drift（含内存缓存支撑少量同步调用点） |
| 迁移服务 | 重写为 Drift 实现，v1→v2→v3 逻辑不变（SQLite VACUUM 导出） |
| 测试 | 全部改用 Drift 内存库（NativeDatabase.memory）；单测 45/45 |
| Windows 构建 | 应用指南补丁：windows_cpp_prefix.h、runner /FI /utf-8 /wd4819、gal WinRT 链接、generated_plugin_registrant 预包含；修复 fvp mdk-sdk 下载（gigenet 镜像）与 install prefix 残留缓存 |
| 构建验证 | ✅ `flutter build windows --debug` 产出 mood_diary.exe；真实 Twenty 集成测试通过 |

遗留说明：
- 旧 Isar 数据库文件不再自动导入（dataMigration 为 no-op），以 SQLite 全新库启动；v1→v2→v3 数据迁移对新库执行。
- fvp 插件需要 mdk-sdk（约 12MB，sourceforge gigenet 镜像可快速下载），已放至 ephemeral 插件目录；新机器可用 `FVP_DEPS_URL` 指向 GitHub Release。
