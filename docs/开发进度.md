## 依赖源根治：flutter_inappwebview 版本锁定（2026-08-21）

用户不设 `PUB_HOSTED_URL` 时 pub 走中国镜像，会把 inappwebview 全家与 `js`/`web`
解析到不兼容的新版，导致 Windows 构建反复失败（`InAppBrowser missing implementations`、
`PlatformWebNotificationController` 缺失等）。本次在 `pubspec.yaml` 增加
`dependency_overrides` 精确锁定兼容版本（镜像源同样生效）：

```yaml
dependency_overrides:
  js: 0.6.7
  web: 1.1.1
  flutter_inappwebview_platform_interface: 1.4.0-beta.2
  flutter_inappwebview_android: 1.2.0-beta.2
  flutter_inappwebview_internal_annotations: 1.2.0
  flutter_inappwebview_ios: 1.2.0-beta.2
  flutter_inappwebview_macos: 1.2.0-beta.2
  flutter_inappwebview_web: 1.2.0-beta.2
  flutter_inappwebview_windows: 0.7.0-beta.2
```

验证：`PUB_HOSTED_URL=https://pub.flutter-io.cn` 环境下 `flutter build windows --debug` ✅（242.9s）。
