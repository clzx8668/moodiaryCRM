## 二、架构决策记录（本里程碑）

1. 放弃 Isar → Drift(SQLite)：持久版本升级兼容（2026-08-20）
2. 放弃 flutter_quill → Markdown + 智能块：内容统一 Markdown（2026-08-19）
3. Flutter 3.41.0 / Dart 3.11（不再锁 3.32）；工具链：build_runner 2.14 / drift_dev 2.30 / json_serializable 6.14 / flutter_gen 5.15
4. flutter_rust_bridge 2.11.1：需 nightly 工具链 + cargo-expand；sync 模块 Cargo feature 门控（sync-engine）避开 codegen MIR 崩溃
5. 目录隔离：新功能全部在 lib/features/，不散落上游 pages

## 四、环境要点（新机器复现）

- Flutter 3.41.0（PATH 默认已是）；nightly Rust + cargo-expand（frb 重生成用）
- pub 源：PUB_HOSTED_URL=https://pub.dev（中国镜像不可达）
- GitHub git 拉取不稳定：进程级注入 ghfast.top 镜像；推送需直连 github.com
- fvp 插件 mdk-sdk：windows/flutter/ephemeral/.plugin_symlinks/fvp/windows/ 下的 7z（sourceforge gigenet 镜像可下载）；.tools/fvp 有本地备份
- 敏感配置 config/twenty.local.json、.tools/ 已 gitignore，不入库
