## 二、架构决策记录（本里程碑）

1. **双模态数据架构**：底层 JSON Block 驱动复杂交互与 AI 解析，展现层 Markdown 驱动阅读与跨端兼容；`metaJson` 自由字段承载业务元数据（source/syncStatus/aiTemplate/dueDate 等），避免频繁改表。
2. **AI 服务商与功能能力分离**（参照 Blinko）：一个 API Key 不通吃四类模型；对话/向量/多模态/语音独立配置，模型从官方列表多选。
3. **同步/备份单一数据契约**：局域网全量同步直接复用备份 zip 格式（manifest + 分域 JSON），extraJson 通道扩展非数据库配置（AI 服务商/能力）。
4. **依赖倒置**：RAG 的 VectorIndex trait 固定，Dart/Drift 向量表与 Rust LocalVectorIndex 均为可用实现，LanceDB 可后续平滑替换。

## 四、环境要点（新机器复现）

- Flutter 3.41.0；Android 构建需 `FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn`（引擎 JAR 走国内镜像）且先 `gradlew --stop` 杀旧 daemon（daemon 只在启动时读取该变量）
- 推送 GitHub 不稳：`git -c http.version=HTTP/1.1 push`（HTTP/2 走本地代理会 Connection reset）
- pub 源：PUB_HOSTED_URL=https://pub.dev；inappwebview 全家已 dependency_overrides 锁版，防镜像升版导致 Windows 构建失败
- fvp 插件 mdk-sdk 依赖网络下载，失败时用 gigenet 镜像；敏感配置（twenty.local.json / API Key）已 gitignore
