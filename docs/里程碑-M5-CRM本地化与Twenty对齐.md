# 里程碑 M5：CRM 本地化 + Twenty 对齐 + 移动端稳定（v2.8.0）

日期：2026-08-25　|　分支：feat/local-crm-v1　|　版本：2.8.0+91
基线：develop（ae71c71，M2/M3/M4 收口）之后 CRM 专项迭代

## 一、背景与目标

按用户决策：**放弃 Twenty 依赖，本地化 CRM**（参照 SuiteCRM/EspoCRM/Twenty 数据模型），
以 Twenty 成熟方案为 UI/交互基准持续对齐；补齐移动端稳定性与数据持久化，达到可日常使用的里程碑。

## 三、关键决策记录

1. **本地优先**：唯一真相源为本地 Drift；Twenty 仅作数据模型与交互参考，不再依赖其服务。
2. **默认仿 Twenty**：UI/交互按 Twenty 源码实证对齐（RecordShowContainer、RelationSection、RecordInlineCell、RecordChip 等）；仅在导航结构差异处做适配（子详情页 + ← 返回，因无整页路由）。
3. **迁移必须幂等**：所有 addColumn 先 PRAGMA 检查；createTable 使用 IF NOT EXISTS。
4. **启动不阻塞**：初始化 await 链全部超时兜底；数据库异常时内存库降级 + 明确提示，不静默丢数据。
