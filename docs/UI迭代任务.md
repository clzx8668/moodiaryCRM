# UI 迭代任务：快速收集面板重构 + 中间详情页（智能块容器）

更新时间：2026-08-20

## 任务 A：快速收集面板（仿 ima AI 交流提交框）

### A1 容器结构
- 单个圆角容器（扁平化，无分割线），自上而下：附件预览行 → 内容输入行 → 行间距 → 功能区。
- 验收：面板主体为一个圆角框；三部分层级清晰；移动端宽度自适应。

### A2 内容输入行
- 多行自适应输入框；空内容时显示灰色提示「发消息或按住说话」。
- 有内容时提示消失。
- 验收：占位文案精确；多行自动增高；空/非空状态提示切换正确。

### A3 语音模式（占位）
- 输入框为空时，按住输入框区域激活"录音中"视觉状态（占位，不接真实识别）；
- 有内容输入后，按住说话失效；
- 功能区提供 语音/键盘 输入状态切换按钮：语音态显示大号「按住 说话」，键盘态显示输入框。
- 验收：空/非空长按行为差异；切换按钮双向可用；语音态不崩溃。

### A4 功能模板
- 左侧模板选择列表：待办、打卡、扩写、润色、会议记录、翻译（PopupMenu）。
- 选择模板后保存：日记自动打上模板标签，并触发"模板 AI 处理"占位钩子（日志 + Toast 提示，真实 AI 后期接入）。
- 验收：模板列表完整；保存后 diary.tags 含模板名；钩子被调用。

### A5 @ 按钮
- 功能区左二 @ 按钮，功能预留（点击 Toast 提示）。

### A6 附件
- 功能区右二「圆圈加号」→ 底部附件列表：图片、声音文件、文档、其他文档。
- 附件在输入行上方缩略图行展示：
  - 图片缩略图 / 音频·文档图标；
  - 缩略图右上角删除符号；
  - 缩略图下方类型提示短句（解读图片 / 转录音频 / 提取文字 / 解析文档）。
- 验收：四类附件可选；缩略图/删除/提示短句齐全；保存后媒体正确落盘（图片→image、音频→audio、文档→Attachments）。

### A7 发送按钮
- 输入为空：隐藏；有输入：显示纸飞机图标按钮。
- 点击发送 = 保存（含模板/附件）并关闭面板。
- 验收：显隐随输入状态切换；发送后成功落盘并关闭。

## 任务 B：中间详情页（Notion 式智能块容器）

### B1 导航链路
- 首页/日历/媒体记录点击 → 中间详情页（SmartCanvasPage，即 DiaryDetailsPage 的块容器形态）；
- 不再直接进入编辑页。
- 验收：三种卡片的 onTap 均进入详情页路由（已满足，回归确认）。

### B2 块容器渲染
- 详情页以智能块列表渲染：text/aiStream（Markdown 渲染）、todo（复选框卡片）、image（图片）、chart/code/smartEntity（类型卡片）；
- 无 Block 时回退整篇 Markdown 渲染。
- 验收：各块类型正确渲染（复用 SmartBlockView，回归确认）。

### B3 块交互
- 点击 Markdown 文本块 → 进入该条记录的 Markdown 编辑器；
- 编辑返回后详情页刷新；
- todo 块点击暂做占位（Toast「待办交互开发中」）；
- 图片块点击放大预览（复用现有图片查看，占位可后续接）。
- 验收：点文本块进编辑器；返回后内容更新；其他块点击不崩溃。
