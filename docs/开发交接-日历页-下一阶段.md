## 5. 关键决策与踩过的坑（别再踩）

1. **不换库**：需求文档点名 `table_calendar + calendar_view`，但拖动新建/移动/改时长/跨天拖期/捏合这些交互它们没有现成实现，
   换库等于推倒重来。结论：自研渲染层 + 借用它们的 API 形状。详见 `docs/日历-需求文档对照与优化分析.md`。
2. **手势竞技场**：把月格放进 `CustomScrollView` / `SingleChildScrollView` 后，滚动视图的拖拽识别器会赢，
   `onScaleUpdate` 永远收不到回调（已最小复现）。规则：**要捏合的组件不能放在滚动容器里**；
   非要在滚动视图里做捏合，就用 `Listener` 原始指针自己算，并**把重建延到下一帧**
   （`addPostFrameCallback`），否则指针派发中重建会触发 `RenderObject` 断言。
3. **一个 `ScrollController` 不能同时挂两棵子树**：视图切换**不要用 `AnimatedSwitcher`**（过渡期两棵树同时持有时间轴的
   controller → "一控多视图"断言）。定位与自动滚动前先判 `controller.positions.length == 1`。
4. **`Get.dialog` + `Get.back(result:)` 在本页面返回 null**（表现是"点了删除没反应"）：确认弹窗统一用
   `showDialog` + `Navigator.of(ctx).pop(true/false)`。
5. **长按冲突**：日格长按（新建）会赢过网格级长按拖动 → 按 iOS 分工：**长按事件条 = 拖动改期，长按空白 = 新建**。
6. **release 打包**：`--split-per-abi` 与 `defaultConfig.ndk.abiFilters` 冲突，已在 `android/app/build.gradle`
   用 `-Psplit-per-abi` 属性分支处理；通用包 250MB，**真机发 arm64 那份（99.4MB）**。
   若要更小，可考虑剔除未用到的原生库（`libonnxruntime.so` 21MB、`libbarhopper_v3.so` 4.7MB 等）。
7. **adb 输入限制**：`input text` 在这台机器上只进首字符，中文更不行 → **自然语言创建、行程时间行这类需要打字的验证
   只能靠单测**（已用单测锁住）。手势可用 `input motionevent DOWN/MOVE/UP`（间隔 ≥120ms，长按需先静止约 900ms）。
8. 手机偶尔 `device offline`：`adb kill-server; adb start-server` 仍不行就请用户解锁手机。
9. 截图识图：主模型可直接看图；`see` skill 用法
   `wsl.exe bash -c "bash /mnt/c/Users/raych/.codex/skills/see/scripts/see.sh 'C:\path\x.png'"`。

## 6. 下次继续做什么（已排好序）

### ① 天气日历

- 项目已配和风天气 Key（`PrefUtil`：`qweatherKey` / `qweatherApiHost`），先搜 `qweather` 找到现有天气服务。
- 目标：日/月视图日期头右侧嵌一条天气（现象 + 温度区间 + 降水概率），设置里可开关；
  或做成"天气订阅日历"写成全天事件（复用 `calendars.source='weather'` 的思路，参考 `holiday_calendar.dart`）。
- 验收：无 Key / 断网不报错也不显示；有 Key 显示当天天气；单测覆盖"解析 + 缓存 + 降级"。

### ② 节气 / 农历 + 节假日在线更新

- 现状：`assets/calendar/china_holidays_2026.json` 随包内置（来源 timor.tech，含调休 39 天）。
- 计划：加"检查更新"按钮拉 `https://timor.tech/api/holiday/year/{year}` 覆盖入库；节气/农历叠加到日期头或月格角标。
- 涉及：`holiday_calendar.dart`（可刷新 + 版本号）、`calendar_manager_sheet.dart`（入口）、资产目录。

### ③ 行程时间自动估算（"该出发了"完全体）

- 现状：`Schedule.travelMinutes` 手动设置；`remindOffsetMin == -1` 时 `remindAt = 开始时间 − 行程时间`。
- 计划：有地点时调地图/路径 API（和风或天地图 Key 都在 `PrefUtil`）估算驾车/步行时长并自动填 `travelMinutes`。
- 涉及：新增 `lib/features/calendar/travel_time.dart`（纯函数 + 可注入网络层）、编辑器「行程时间」行加"自动估算"。

- 侧边栏右键菜单（重命名/改色/共享/删除/仅显示此日历）、事件块悬停 Tooltip、**年视图**；
