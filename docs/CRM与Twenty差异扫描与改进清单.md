# CRM 与 Twenty 差异扫描与改进清单

> 版本：v1.0 · 2026-08-24 · 分支：feat/local-crm-v1
> 原则：样式、功能、UI 交互无限贴近 Twenty；客户表特殊要求全局复用；充分利用 pluto_grid 能力。

## 一、扫描范围

`lib/features/crm/`（首页 Tab、表格、右侧栏详情、关联、字段、设置）+ `test/crm/`。

### 一致性保障

- 全部基础对象（account/contact/opportunity/contract/quote/…）与自定义对象共用同一 `CrmSmartTable` 与 `CrmRecordDetailShell`，客户表特殊要求（关联区块、字段冲齐、标签流、批量条）自动复用到所有表；
- 表格列设置、隐藏、宽度、显隐开关均按对象类型分键持久化，互不干扰。

## 三、本批改进（2026-08-24）

1. 数字/金额列右对齐 + 表头对齐（Twenty 数字列惯例）；
2. 当前行高亮（rowColorCallback，极淡 primaryContainer）；
3. 列宽记忆：调整后防抖持久化 `crmTableWidths_<type>`（已入 PrefUtil 白名单），下次打开还原；
4. 长文本单元格 hover Tooltip（600ms 延迟，不遮挡编辑）；
5. 详情字段行 hover 高亮（与 Twenty 字段行悬停反馈一致）。

## 四、已知取舍与后续候选

| 项 | 说明 |
| :-- | :-- |
| 列宽拖拽 | 因“无列标题图标”要求已禁用 pluto 的图标拖拽（enableDropToResize=false）；用右键「自动适配」+ 列宽记忆补偿。若需拖拽可恢复并接受标题右侧小图标 |
| 行 hover 全行变色 | pluto 无内置行 hover，当前以「当前行高亮」替代；如需 hover 可在 renderer 层做 MouseRegion（成本较高，待需要时做） |
| 表头分组 | Twenty 无列分组，暂不启用 pluto column group |
| 表格行展开（RecordRow） | Twenty 表格无行内展开（详情在右侧栏/整页），维持双击下钻 |
| 单元格过滤行常驻 | Twenty 筛选走列菜单弹出，保持现状（不常驻过滤行） |
