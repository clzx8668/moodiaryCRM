# 需求文档对照与优化分析（批次 129）

> 对照对象：`D:\下载\仿苹果原生日历应用Flutter开发设计需求文档.docx`（629 段，含 Token 表与示例代码）
> 对照现状：批次 125–128 已落地的 iOS 18 风日历（`lib/features/calendar/`）

---

## 1. 一句话结论

**渲染层不建议换库，交互层我们已经超出文档要求；真正该补的是「设计系统 Token + 苹果色系 + 触感/动效细节」。**

文档点名 `table_calendar + calendar_view`。这两个库解决的是"把日历画出来"，而本项目已经做到文档交互章节（§3.3/§5.2）要求的**长按拖拽新建、拖动改时间、拖手柄改时长、跨天拖动改期、双指捏合三档、月↔周滑动**——这些在 table_calendar / calendar_view 里都**没有现成实现**（calendar_view 只提供 `eventTileBuilder` 定位，拖拽要自己写）。换库等于把三轮交互推倒重做，收益为负。

所以这一轮做的是：**把文档 §6 的 Token 体系与苹果色系真正落到日历页**，并补齐触感与动效细节；库的 API 形状（`eventLoader` / `markerBuilder` / `heightPerMinute` / `SideEventArranger`）作为我们纯函数接口的设计参照。

## 3. 本轮（批次 129）实际改动

1. **苹果色系 Token 落地**：`IosCalendarTheme` 新增主色 `#007AFF/#0A84FF`、次级文字 `#8E8E93`、
   分隔线 `#C6C6C8/#38383A`、次级背景 `#F2F2F7/#1C1C1E`，以及 space/radius/尺寸/动画常量；
   日历页用 `IosCalendarTheme.scoped()` 套一层局部 Theme（**不动全局主题**，其它页面不受影响）。
2. **触感反馈**：进入拖动（长按）、捏合换档、切换视图模式都触发 `HapticFeedback`（文档 §3.2/§5.2）。
3. **动效**：视图/页签切换改为 `AnimatedSwitcher`（0.3s easeInOutCubic，§5.1）。
4. **时间轴细节**：整点实线 + **半点虚线**；事件块圆角 6pt、底色 20% 透明（§3.3）。
5. **提醒事项**：已完成项弱化到 60% 但不隐藏（§3.4）。
6. **搜索关键词高亮**（§5.5）。
7. **PC 端**：侧边栏 240 / 详情 320（§4.1）；**ESC 收起右侧检查器**（§4.4）。
